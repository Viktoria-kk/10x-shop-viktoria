# 10X Shop project guidance

- Use the installed Impeccable skill for frontend design, visual hierarchy, spacing, typography, responsiveness and UI refinement. Use Ponytail's simplicity-first review when its skill is available; never claim an unavailable skill was invoked.
- Follow the existing palette and design system. Prefer current React components, Tailwind utilities and native browser features; add dependencies or abstractions only for a clear need.
- Preserve accessibility, validation, error handling and working shopping behaviour. Keep the code easy to explain during the graduation defence.
- Do not start the app, development server or browser. The project owner manages previews.
